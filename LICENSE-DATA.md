# Data licence

The inventory data in `base/`, `ledger/` and `build/` (the assessments, checks, notes and evidence links) is shared under the
[Creative Commons Attribution 4.0 International licence (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
Attribution: "Gaia data inventory, OHDSI GIS Working Group".

The datasets the inventory describes are not covered by this licence: each keeps its publisher's own terms, recorded per row
(`license_confirmed`, `license_class`).
