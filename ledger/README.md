# Ledger

Every change since `base/inventory-base.csv`, one file per contribution, applied in file-name order by `scripts/build.py`.
Append-only: to correct a value, add a new file that sets it again (with evidence). Don't edit a merged file.

File name: `<YYYY-MM-DD>-<github-handle>-<slug>.jsonl`. The first line is the session's effort (`{"meta": …}`), which feeds the estimates. Record format: `.claude/skills/inventory/SKILL.md`, section 5.
`packets/<id>.json`: schema packets from packet c.
